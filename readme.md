# Pomodoro Timer

A Pomodoro timer built with vanilla HTML, CSS, and JavaScript.

**Live demo:** https://pomodoro-timer-xi-two.vercel.app/

## How to run

You only need a browser. No installs required.

**Just open the file:**
```
double-click index.html
```

## Features

- Configurable focus and break durations
- Animated progress ring with color shifts
- Audible chime when a session ends
- Session history saved per day (resets the next day)
